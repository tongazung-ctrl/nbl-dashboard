# แดชบอร์ดหนองบัวลำภู

เว็บสาธารณะฟรีสำหรับดูอากาศและจุดรับซื้อผลผลิตเกษตรในจังหวัดหนองบัวลำภู ไม่ต้องเข้าสู่ระบบ

**ลิงก์ที่ตั้งใจให้เปิดดู:** https://tongazung-ctrl.github.io/nbl-dashboard/

หน้านี้มี

- แผนที่ 6 อำเภอ จุดรับซื้อ 16 แห่ง และเอฟเฟกต์อากาศ
- ค้นหาและเลือก อำเภอ → ตำบล → หมู่บ้าน พร้อมพยากรณ์ 7 วันและสถานีฝนใกล้สุด
- หมายเหตุความละเอียดจริง ~9 กม. (โมเดล ECMWF IFS ผ่าน Open-Meteo)
- ราคาอ้างอิงพร้อมแหล่ง และเบอร์โทรตามที่มีในแหล่งเปิดเผย
- ส่วนแหล่งข้อมูลและความละเอียด
- ชั้นแหล่งท่องเที่ยวในจังหวัดจาก ททท. (ตรวจพิกัดกับ OSM แล้ว; ทะเลบัวแดงเป็นทริปใกล้เคียงที่อุดรธานี ไม่ปักในแผนที่จังหวัด)
- ฝุ่น PM2.5 จากสถานี Air4Thai รหัส 115t และพยากรณ์โมเดล Open-Meteo (คนละแหล่ง)
- กราฟราคาย้อนหลังของผลผลิตที่มีชุดข้อมูล
- ปฏิทินเพาะปลูกตามกรอบฤดูกรมอุตุฯ และคำแนะนำจากพยากรณ์ 7 วัน (เงื่อนไขในไฟล์ตั้งค่า)
- เตือนฝนเทียบเกณฑ์กรมอุตุฯ จากสถานี ThaiWater
- หน้า [เที่ยวช่วงไหนดี](./climate.html) จากค่าปกติฝน 30 ปีและสถิติรายเดือน
- ลิงก์ช่วยเหลือ ธ.ก.ส. / กรมส่งเสริมการเกษตร และปุ่มนำทางไปจุดบนแผนที่

พยากรณ์รายอำเภอและรายช่องกริดพยายามดึงสดจาก Open-Meteo ในเบราว์เซอร์ (มี CORS) ถ้าดึงไม่ได้จะใช้ไฟล์ JSON สำรองในคลังนี้ ฝนวัดจริงจาก ThaiWater และพยากรณ์ทางการกรมอุตุฯ ใช้ข้อมูลสำรองที่อัปเดตรายวัน เพราะ API เหล่านี้อาจไม่เปิดให้เบราว์เซอร์เรียกข้ามเว็บ

วิธีอัปเดตข้อมูลและเผยแพร่บน GitHub Pages อยู่ใน [PUBLISH_HOWTO.md](./PUBLISH_HOWTO.md)
